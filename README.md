# Mamba-Narrative

## Status
Ongoing Major Project (7th Semester)

## Overview
Mamba-Narrative is an AI-powered video summarization using Mamba State Space Models, Reinforcement Learning, and Large Language Models to generate concise and meaningful video summaries.

## Current Progress
- Literature survey completed
- Dataset preparation completed
- Feature extraction implemented
- Mamba-based sequence modeling implemented
- Reinforcement Learning pipeline developed
- LLM-guided captioning integrated
- Project under active development

## Technologies Used
- Python
- PyTorch
- Computer Vision
- Reinforcement Learning
- Large Language Models (LLMs)
- Google Colab
